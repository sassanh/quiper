# Setting Up Engines

Guides that take you from a clean slate to a working AI engine inside Quiper — no matter where you start, after following one of these guides, that engine works.

## Available guides

- [Setting Up ChatGPT](engines-setup/chatgpt.md) — install Quiper, create an OpenAI account if you don't have one, and sign in to ChatGPT inside the overlay.
- [Setting Up Gemini](engines-setup/gemini.md) — install Quiper, create a Google account if you don't have one, and sign in to Gemini inside the overlay.
- [Setting Up Grok](engines-setup/grok.md) — install Quiper, create an xAI account if you don't have one, and sign in to Grok inside the overlay.
- [Setting Up DeepSeek](engines-setup/deepseek.md) — install Quiper, create a DeepSeek account if you don't have one, and sign in to DeepSeek inside the overlay.
- [Setting Up Qwen](engines-setup/qwen.md) — install Quiper, create a Qwen account if you don't have one, and sign in to Qwen inside the overlay.
- [Setting Up OpenCode](engines-setup/opencode.md) — install Quiper, install OpenCode and start its local server, and open it inside the overlay.

Any sign-in flow that tries to leave the overlay has fixes that don't require editing rules — see [Keeping Sign-In Inside the Overlay](engines-setup/sign-in-routing.md).

More engine guides are on the way. Every engine Quiper ships with follows the same path — install, open the engine, sign in where the engine needs an account, verify — and the [Managing Engines](engines.md) reference covers the configuration details for all of them in the meantime.
