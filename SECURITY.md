# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

Download the latest release from the [Releases](https://github.com/sassanh/quiper/releases/latest) page before reporting.

## Reporting a Vulnerability

Do not open a public issue, discussion, or pull request for a suspected vulnerability.

Report privately via [GitHub security advisories](https://github.com/sassanh/quiper/security/advisories/new). Include:

- Quiper version and macOS version
- Steps to reproduce
- What an attacker can achieve (data read, code execution, persistence, bypass of Touch ID locking)
- Logs or screenshots, if relevant

For background on the local threat model, see `docs/security.md`.

## Response

- Acknowledgement within 5 business days.
- Fix or mitigation in the next release when confirmed.
- Public disclosure only after a fix is available; credit on request.
